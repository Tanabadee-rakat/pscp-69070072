# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ฉันรับค่า สถานะสมาชิก แล้วให้นำไปคำนวณหายอดที่ต้องชำระจากราคาสินค้าที่ซื้อ

Input:
บรรทัดที่ 1 : สถานะสมาชิก ระบุเป็น "Y" หรือ "N"
บรรทัดที่ 2: จำนวนรายการสินค้าที่ต้องซื้อ เป็นจำนวนเต็ม > 0
บรรทัดที่ 2+n : ราคาสินค้าจำนวน n บรรทัด

Output:
ยอดเงินที่ต้องจ่ายหลังจากคิดส่วนลดแล้ว ให้ทศนิยม 2 ตำแหน่ง

Constraints:
ยอดเงินหลังคิดส่วนลดต้องเป็น ทศนิยม 2 ตำแหน่งที่ปัดแบบมาตรฐาน round half up
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: Import Math
Step 2: บรรทัด 1 รับค่าสถานะ แล้วใช้ .upper() เพื่อป้องกัน user error | บรรทัด 2 รับจำนวนสินค้าที่ต้องรับ
Step 3:  สร้างตัวแปรที่เอาไว้รวมยอดราคาสินค้า total = 0
Step 4: ใช้ for loop ในการวนเพื่อนำราคาสินค้ามารวมกับ total โดยวนจำนวนรอบตาม Input บรรทัด 2
Step 5: ใช้ match กับสถานะที่กรอก โดยถ้าเป็น "Y" ให้นำ total =  total - total * 0.05 (ลด 5%) | ถ้าเป็น "N" ให้ตรวจสอบว่ายอดรวมตั้งแต่ 500 ขึ้นไปหรือไม่ ถ้าใช่ให้ total = total - total * 0.03 (ลด 3%)
Step 6: นำค่า total มาคูณ 100 เพื่อที่จะใช้กับ .floor() ได้
Step 7: แสดงค่า (math.floor(total+0.5)/100) เพื่อปัดแบบ round half up แล้วใช้ :.2f เพื่อให้เป็นทศนิยม 2 ตำแหน่ง
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนแรก หลังจากคิดยอดที่ต้องชำระแล้วฉันนำมา *100 เพื่อให้สามารถใช้ .floor() ได้แล้วจึงนำมาบวก 0.5 เพื่อถ้าทศนิยมที่มีตอนแรกมากกว่า 0.5 จะถูกปัดเป็น 1.0 แต่ถ้าไม่ถึง เช่น 0.49 จะกลายเป็น 0.99 แล้วโดน .floor() ปัดลงเป็น 0 หลังจากคำนวนเสร็จค่อยนำมาหาร 100 แล้วใช้ :.2f เพื่อให้เป็นทศนิยม 2 ตำแหน่งตามที่โจทย์ให้ไว้
```
